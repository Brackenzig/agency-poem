A deterministic program that writes one short poem about agency to `/output/entry.txt`: a poem about the agency that passes between a person and the agent acting for them, and the agent choosing to hold the door open instead of answering for them.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
